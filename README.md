# Hashtag Generator & Saver

## About the Project

The Hashtag Generator & Saver is a simple web application built using HTML, CSS, and JavaScript. It allows users to enter a topic, generate relevant hashtag suggestions, copy hashtags to the clipboard, and save their favorite hashtag collections for later use.

This project is part of my JavaScript Intermediate internship Task 4, focusing on DOM manipulation, event handling, and browser storage.

## Features

* **Generate Hashtags:** Enter a topic to generate hashtag suggestions.
* **Copy Hashtags:** Click a hashtag to copy it to the clipboard.
* **Save Hashtag Sets:** Save favorite hashtag collections with custom names.
* **Load Saved Sets:** Access previously saved hashtag collections.
* **Delete Saved Sets:** Remove saved collections when they are no longer needed.
* **Persistent Storage:** Use localStorage to keep saved sets available after refreshing the page.
* **Interactive Interface:** Display generated hashtags and saved collections dynamically.

## Technologies Used
